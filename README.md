## ตัวแปรสำหรับการจูนค่าใน Live Expressions

### Process Noise (เมทริกซ์ Q)
* `TUNING_Q_pos_noise` (ค่าเริ่มต้น: `0.001f`): ความแปรปรวนของสเตตตำแหน่ง
* `TUNING_Q_vel_noise` (ค่าเริ่มต้น: `0.01f`): ความแปรปรวนของสเตตความเร็ว
* `TUNING_Q_current` (ค่าเริ่มต้น: `0.1f`): ความแปรปรวนของกระแสไฟฟ้าในมอเตอร์
* `TUNING_Q_disturbance` (ค่าเริ่มต้น: `10.0f`): ความไวในการตามจับแรงบิดรบกวนภายนอก **(จุดหลักในการจูน)**

### Measurement Noise (ค่า R)
* `TUNING_R_sensor_noise` (ค่าเริ่มต้น: `0.05f`): ความแปรปรวนของเซนเซอร์ Encoder
  * **ถ้าปรับค่า R สูงขึ้น**: ตัวกรองจะเชื่อแบบจำลองคณิตศาสตร์มากกว่าเซนเซอร์ สัญญาณจะเนียนขึ้น แต่จะเกิดอาการหน่วงหรือเฟสแลก
  * **ถ้าปรับค่า R ต่ำลง**: ตัวกรองจะเชื่อเซนเซอร์จริงหน้างานมากขึ้น ระบบตอบสนองไว ไม่หน่วง แต่สัญญาณรบกวนจาก Encoder จะทะลุเข้ามาทำให้ระบบสั่น

## ขั้นตอนการทดลองและการบันทึก Log

1. แอดตัวแปรเหล่านี้ลงในหน้าต่าง Live Expressions เพื่อมอนิเตอร์:
   * `g_arm.raw_enc_deg` (องศาดิบจาก Encoder)
   * `g_arm.pos_deg` (องศาที่ผ่าน Kalman Filter แล้ว)
   * `g_arm.vel_deg_s` (ความเร็วที่ผ่าน Kalman Filter แล้ว)
   * `g_arm.disturbance_nm` (ค่าภาระโหลดรบกวนภายนอก)
2. เปิดโปรแกรม STM32CubeMonitor หรือเครื่องมือดูด Log เพื่อพล็อตและเซฟค่าตัวแปรออกเป็นไฟล์ `.csv` หรือ Excel
3. ป้อนค่า Q และ R ชุดที่ต้องการทดสอบใน Live Expressions ตามตารางการทดลอง
4. ตั้งระยะองศาที่ต้องการทดสอบในช่อง `COMMAND_target_deg` (เช่น `90.0`) และตั้งทิศทางในช่อง `COMMAND_direction` (`1.0f` หรือ `-1.0f`)
5. กดเริ่มบันทึกข้อมูลในโปรแกรม Log
6. เปลี่ยนค่าตัวแปร `TRIGGER_execute_move` **จาก `0` ให้เป็น `1`** แล้วกด Enter แขนกลจะหมุนทันทีตามโปรไฟล์ S-Curve
7. เมื่อแขนกลวิ่งไปถึงจุดหมายและหยุดนิ่ง ให้กดหยุดบันทึกข้อมูล แล้ว Export ไฟล์ออกมาเพื่อเตรียมนำไปพล็อตกราฟเปรียบเทียบใน MATLAB

## ตารางแผนการทดลองทั้ง 6 รอบ (Tuning Matrix)

เมื่อตั้งค่าการอ่าน Encoder แบบ X4 (8192 พัลส์ต่อรอบ) จะได้ค่า R ฐานทางทฤษฎีคือ $R_0 = 4.90229 \times 10^{-8}$ และค่า Q ฐานคือ $Q_0 = \text{diag}(10^{-8}, 10^{-4}, 10^{-3}, 10^{-1})$ ให้กรอกค่าในแต่ละรอบการทดลองดังนี้:

| ครั้งที่ | รูปแบบการทดลอง | ค่า Matrix Q | ค่า R | ผลลัพธ์ที่คาดว่าจะเกิดขึ้น |
| :---: | :--- | :--- | :--- | :--- |
| **1** | ล็อค Q, ปรับ R ให้มากกว่า | $\text{diag}(10^{-8}, 10^{-4}, 10^{-3}, 10^{-1})$ | **$4.90229 \times 10^{-6}$** *(R0 $\times$ 100)* | สัญญาณเรียบเนียนมาก แต่ระบบตอบสนองช้า มีอาการหน่วงและเกิด Overshoot สูงขึ้น |
| **2** | ล็อค Q, ปรับ R ให้เท่ากับ | $\text{diag}(10^{-8}, 10^{-4}, 10^{-3}, 10^{-1})$ | **$4.90229 \times 10^{-8}$** *(R0 Baseline)* | จุดสมดุลระบบ สัญญาณเรียบเนียนและไม่หน่วงเกินไป แขนกลเคลื่อนที่ได้นิ่ง |
| **3** | ล็อค Q, ปรับ R ให้น้อยกว่า | $\text{diag}(10^{-8}, 10^{-4}, 10^{-3}, 10^{-1})$ | **$4.90229 \times 10^{-10}$** *(R0 / 100)* | ตอบสนองไวมาก ไม่มีอาการหน่วง แต่สัญญาณจะสั่นและมี Noise ฟันปลาทะลุเข้ามาสูง |
| **4** | ปรับ Q ให้น้อยกว่า, ล็อค R | **$\text{diag}(10^{-10}, 10^{-6}, 10^{-5}, 10^{-3})$** *(Q0 / 100)* | $4.90229 \times 10^{-8}$ | ตัวกรองเชื่อโมเดลคณิตศาสตร์มากเกินไป สัญญาณนิ่ง แต่จะเพิกเฉยต่อโหลดรบกวนภายนอก |
| **5** | ปรับ Q ให้เท่ากับ, ล็อค R | **$\text{diag}(10^{-8}, 10^{-4}, 10^{-3}, 10^{-1})$** *(Q0 Baseline)* | $4.90229 \times 10^{-8}$ | ชุดควบคุมกลุ่มตัวอย่าง (ผลลัพธ์จะเทียบเท่ากับรอบที่ 2 เพื่อรีเช็กความถูกต้อง) |
| **6** | ปรับ Q ให้มากกว่า, ล็อค R | **$\text{diag}(10^{-6}, 10^{-2}, 10^{-1}, 10^{1})$** *(Q0 $\times$ 100)* | $4.90229 \times 10^{-8}$ | ตัวกรองเชื่อเซนเซอร์มาก ระบบตามจับแรงบิดรบกวนภายนอกได้ไวที่สุด แต่สัญญาณจะสั่นคราง |

*หมายเหตุ: คำว่า $\text{diag}(a,b,c,d)$ คือเมทริกซ์ขนาด $4 \times 4$ ที่มีค่าแนวทแยงมุมตามตัวเลขนั้น ๆ และตำแหน่งอื่นรอบ ๆ เป็น 0 ทั้งหมด*

เมื่อเก็บไฟล์ครบทั้ง 6 เคสแล้ว ให้นำไปพล็อตกราฟเปรียบเทียบใน MATLAB หาค่าชุดที่ให้ Settling Time ต่ำที่สุด โดยไม่มี Noise ฟันปลาแหลมในสัญญาณความเร็ว เพื่อสรุปเป็นค่าที่ดีที่สุดของระบบ
