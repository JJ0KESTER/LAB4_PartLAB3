# 1-DOF Robot Arm - Kalman Filter Q & R Tuning Environment

คู่มือสำหรับการใช้งานระบบควบคุมและตัวประมาณค่าสถานะ (State Estimator) แบบ **4-State Discrete Kalman Filter** ร่วมกับระบบวางเส้นทาง **7-Phase S-Curve Trajectory** บนบอร์ด **STM32G474xx** เพื่อค้นหาค่าความแปรปรวน (Covariance Matrices) $Q$ และ $R$ ที่เหมาะสมที่สุด ซึ่งจะทำให้แขนกลเคลื่อนที่ได้นิ่งและเสถียรที่สุด

---

## 1. จุดประสงค์ของการทดลอง (Experiment Objectives)
1. **Noise Filtering**: เพื่อกรองสัญญาณรบกวนความถี่สูง (Sensor Jitter) ออกจากเซนเซอร์ Encoder ดิบที่ติดตั้งอยู่ฝั่ง Shaft Output
2. **State Estimation**: เพื่อประเมินค่าความเร็ว (Velocity) และค่าแรงบิดรบกวนภายนอก (Disturbance Torque) ที่มีความแม่นยำสูง นำไปจ่ายให้ระบบควบคุม Cascade PID
3. **Data Logging Analysis**: บันทึกข้อมูลผลการตอบสนองเชิงเวลา (Time-Response) ออกมาเป็นไฟล์ `.xlsx` เพื่อนำไปวิเคราะห์กราฟ, คำนวณค่า Overshoot, และหา Settling Time ในโปรแกรม **MATLAB**

---

## 2. คัมภีร์การปรับจูนพารามิเตอร์ (Tuning Parameters Guide)

ตัวแปรสำหรับการปรับจูนจะประกาศเป็น `volatile float` อยู่ที่ส่วน pv ของไฟล์ `main.c` สามารถเปิดหน้าต่าง **Live Expressions** ใน STM32CubeIDE เพื่อดับเบิ้ลคลิกแก้ไขค่าได้แบบ Real-time:

### 2.1 Matrix Q (Process Noise Covariance - ความน่าเชื่อถือของแบบจำลองคณิตศาสตร์)
Matrix $Q$ เป็นตัวบอกว่าแบบจำลองคณิตศาสตร์ของมอเตอร์ในบอร์ดมีความแม่นยำแค่ไหน ยิ่งตั้งค่าน้อย แปลว่าเรา "เชื่อมั่นในสมการ" มากกว่าเซนเซอร์
* **`TUNING_Q_pos_noise`** *(ค่าเริ่มต้น: `0.001f`)*: ความแปรปรวนของตำแหน่ง
* **`TUNING_Q_vel_noise`** *(ค่าเริ่มต้น: `0.01f`)*: ความแปรปรวนของความเร็ว
* **`TUNING_Q_current`** *(ค่าเริ่มต้น: `0.1f`)*: ความแปรปรวนของกระแสไฟฟ้าในขดลวด
* **`TUNING_Q_disturbance`** *(ค่าเริ่มต้น: `10.0f`)*: **[จุดสำคัญ]** บ่งบอกความไวในการจับแรงบิดรบกวนภายนอก (Disturbance Torque) 
  * *ข้อแนะนำ*: หากตั้งค่านี้ **สูงขึ้น** ตัวกรอง Kalman จะวิ่งไล่ตามแรงกระตุกหรือโหลดภายนอกได้เร็วขึ้น แต่ถ้าสูงเกินไป สัญญาณความเร็วจะเริ่มมี Noise

### 2.2 Matrix R (Measurement Noise Covariance - ความแปรปรวนของเซนเซอร์ดิบ)
* **`TUNING_R_sensor_noise`** *(ค่าเริ่มต้น: `0.05f`)*: ตัวบอกระดับรบกวนของ Encoder Hardware ที่ Shaft Output
  * *หลักการจูน*:
    * ถ้าเพิ่มค่า $R$ **สูงขึ้น**: ตัวกรองกัลมานจะมองว่าเซนเซอร์มี Noise เยอะ มันจะหันไปเชื่อแบบจำลองคณิตศาสตร์มากขึ้น ผลคือ **สัญญาณจะนิ่งและสมูทขึ้นมาก แต่จะเกิดอาการหน่วง (Phase Lag)**
    * ถ้าลดค่า $R$ **ต่ำลง**: ตัวกรองจะวิ่งเข้าหาค่าดิบจากเซนเซอร์ไวขึ้น ผลคือ **ระบบตอบสนองไว ไม่หน่วง แต่ Noise และอาการสั่นฟันปลาจาก Encoder จะทะลุเข้ามาในระบบควบคุม**

## 3. ขั้นตอนการทดลองและการเก็บข้อมูล (Step-by-Step Test Procedure)

### สเต็ปที่ 1: เตรียมระบบตรวจวัดข้อมูล
1. เชื่อมต่อบอร์ด STM32 เข้ากับคอมพิวเตอร์ และเปิดโปรแกรม **STM32CubeIDE**
2. เปิดหน้าต่าง **Live Expressions** แล้วแอดตัวแปรเหล่านี้ลงไปเพื่อสังเกตการณ์:
   * `g_arm.raw_enc_deg` *(พิกัดดิบจาก Encoder)*
   * `g_arm.pos_deg` *(พิกัดที่ผ่าน Kalman Filter แล้ว)*
   * `g_arm.vel_deg_s` *(ความเร็วที่ผ่าน Kalman Filter แล้ว)*
   * `g_arm.disturbance_nm` *(ค่าภาระโหลดรบกวนภายนอก)*
3. เปิดโปรแกรมบันทึกสัญญาณ เช่น **STM32CubeMonitor** หรือเครื่องมือบันทึก Log ของกลุ่ม เพื่อเตรียมพล็อตและดึงค่าตัวแปรด้านบนออกเป็นไฟล์ `.csv` หรือ `.xlsx`

### สเต็ปที่ 2: ตั้งค่าจูนทดสอบ
1. ตรวจสอบให้มั่นใจว่าก้านแขนกลว่างเปล่าและปลอดภัยต่อการหมุน
2. ป้อนค่า $Q$ และ $R$ ชุดที่ต้องการทดสอบในหน้าต่าง Live Expressions
3. ป้อนระยะองศาที่ต้องการให้หุ่นยนต์สะบัดตัวทดสอบในช่อง **`COMMAND_target_deg`** (เช่น `90.0` หรือ `180.0` องศา)
4. ป้อนทิศทางในช่อง **`COMMAND_direction`** (`1.0f` = ทวนเข็ม CCW / `-1.0f` = ตามเข็ม CW)

### สเต็ปที่ 3: กระตุ้นคำสั่ง (Execute Step Response)
1. กดเริ่มบันทึกข้อมูล (Start Logging) ในโปรแกรมบันทึกผล
2. ที่ตัวแปร **`TRIGGER_execute_move`** ให้ดับเบิ้ลคลิกเปลี่ยนค่าจาก **`0` ให้เป็น `1`** แล้วกด Enter
3. บอร์ด STM32 จะสั่งให้ก้านแขนกลหมุนดีดตัวตามโปรเฟส S-Curve ทันที ตัวแปรจะถูกล้างกลับเป็น 0 อัตโนมัติ
4. รอจนกระทั่งก้านแขนกลหยุดนิ่งสนิท จากนั้นกดหยุดบันทึกข้อมูล (Stop Logging) แล้วทำการ Export ข้อมูลรอบนั้นออกเป็นไฟล์รูปแบบ `.xlsx`

| :---: | :---: | :---: | :--- | :--- |
| **1.1** | `0.001` (ต่ำมาก) | `10.0` (คงที่) | เชื่อเซนเซอร์ดิบมากเกินไป | หุ่นมีอาการสั่นสะท้าน, กราฟความเร็วมี Noise สูง |
| **1.2** | `0.05` | `10.0` (คงที่) | [Baseline] เริ่มกรอง Noise | สัญญาณสมูทขึ้น แขนกลหมุนนิ่งขึ้น |
